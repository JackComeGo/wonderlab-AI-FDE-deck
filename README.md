# Wonderlab AI FDE 分享 Deck

这是一个可直接发布到 GitHub Pages 的单文件 H5 Deck。

## 发布方式

1. 新建或打开一个 GitHub 仓库。
2. 上传本目录下的 `index.html` 和 `.nojekyll`。
3. 在 GitHub 仓库 Settings → Pages 中选择部署分支，例如 `main` / root。
4. 等待 GitHub Pages 构建完成后，访问生成的 Pages 链接。

## 文件说明

- `index.html`：已内联的单文件 Deck，可直接分享。
- `.nojekyll`：避免 GitHub Pages 对文件做 Jekyll 处理。
